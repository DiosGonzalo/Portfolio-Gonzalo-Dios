🚀 Portfolio de Desarrollador Web

¡Bienvenido a mi portfolio personal! 
Este sitio está diseñado para mostrar mi experiencia, habilidades y proyectos.Construido con la velocidad y eficiencia de Astro y estilizado con la utilidad de Tailwind CSS.

✨ Características Principales
Diseño Moderno (Dark Mode): Estilo limpio y profesional con una paleta de colores distintiva (Azul, Dorado, Verde).One-Page Layout: Experiencia de usuario fluida con navegación basada en anclas.
Diseño Responsivo: Optimizado para escritorio, tabletas y dispositivos móviles (Mobile-First).
Stack Tecnológico Claro: Secciones dedicadas a la Experiencia y Tecnologías utilizadas.
Rendimiento: Puntuación alta en Lighthouse gracias a Astro.
